# Nanakusa Nazuna Codex Pet

`Nazuna Byte` is a fan-made animated pet for the Codex desktop app, inspired by Nazuna Nanakusa from *Call of the Night*.

![Running right](previews/running-right.gif)
![Running left](previews/running-left.gif)

## Install

Clone this repository, then copy the two pet files into the Codex custom-pet directory:

```bash
mkdir -p "$HOME/.codex/pets/nazuna-byte"
cp pet.json spritesheet.webp "$HOME/.codex/pets/nazuna-byte/"
```

Select `Nazuna Byte` in Codex. If the old artwork is still cached, switch to another pet and select it again.

## Package

- Pet ID: `nazuna-byte`
- Display name: `Nazuna Byte`
- Sprite contract: Codex v2 (`spriteVersionNumber: 2`)
- Atlas: `1536×2288` WebP, `8×11` cells
- SHA-256: `eef0d4710746c6665bf2525dc37a9e9196dff16592cd86fe54fc6dbfee81ac83`
